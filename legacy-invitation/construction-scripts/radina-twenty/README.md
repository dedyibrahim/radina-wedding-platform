# Historical construction helpers

These one-time scripts created the twenty-template upgrade. Do not run them on a maintained installation: they generate initial source files and can overwrite later presentation edits. Runtime code does not import them.

Maintained components are in frontend/src/templates; canonical defaults are in backend/config/template-presets.json. The catalog and experience seeders install included assets without rebuilding source. Optional asset preparation and browser validation scripts remain in scripts.
